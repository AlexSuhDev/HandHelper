# Город рядом · HandHelper

Единый локальный сайт городских сервисов с адаптацией интерфейса. Пользователь работает с обращениями, услугами и новостями; администратору на той же странице доступны показатели взаимодействия и инструменты модели.

## Запуск

Для входа администратора и сохранения статистики запустите встроенный локальный сервер. На Windows используется PowerShell и установленный .NET Framework; установка Python, Node.js и сторонних библиотек не нужна. Сохраняйте всю папку проекта, включая `server` и `js`.

Для запуска по HTTP на Windows:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Start-Preview.ps1
```

Адрес: `http://127.0.0.1:8741/`. Для другого порта добавьте `-Port 8742`.

При первом запуске сервер создаёт администратора с логином **admin** и случайным паролем. Пароль показывается в терминале один раз. Сохраните его; в файле `.data/admin.json` хранится только соль и PBKDF2-SHA256 хеш, исходный пароль не записывается. Чтобы назначить новый пароль, остановите сервер и выполните:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Start-Preview.ps1 -ResetAdminPassword
```

Новый пароль вводится скрыто и должен содержать от 5 до 256 символов. Существующая статистика при смене пароля сохраняется.

Открытие `index.html` через `file://` оставляет доступными обычные действия с сайтом и настройку интерфейса; вход и серверная статистика работают через HTTP. Сервер слушает только `127.0.0.1`, то есть доступен на этом компьютере.

## Один сайт, два режима

- Обычный пользователь видит услуги, обращения, новости и настройки интерфейса.
- Нажмите **«Вход администратора»** в шапке и введите логин и пароль. После входа на той же странице появятся статистика, аналитика, модель и кнопка выхода.
- Старый адрес `index.html?role=admin` теперь только открывает форму входа и не выдаёт права.

Доступ к статистике проверяется сервером при каждом запросе. Сессия хранится в HttpOnly/SameSite=Strict cookie и действует один час; обновление страницы сохраняет вход. Выход и перезапуск сервера завершают сессию. После пяти неверных попыток вход блокируется на пять минут. Сервер проверяет источник изменяющих запросов, а выход также требует CSRF-токен. Скрытие разделов в браузере служит только отображению: персональные серверные данные защищены проверкой сессии в API.

## Статистика администратора

В кабинете доступны периоды 7 дней, 30 дней и всё время, восемь сводных показателей, график сеансов по дням, распределение выбранных вариантов интерфейса и последние 50 сеансов. CSV выгружает эти последние сеансы за выбранный период. Время начала в таблице отображается по часовому поясу браузера; дневные группы считаются по UTC. Период отбирает сеансы по дате начала.

Учитываются только сеансы пользователей, давших согласие на статистику: активное время, числа нажатий и кликов, создания обращений, выборы услуг, показ и принятие автоматического предложения адаптации, выбранные размеры интерфейса. Сеансы имеют случайный код; это не число уникальных людей. Создание обращения учитывается как действие, даже если затем нажата отмена. Синтетические сценарии не подмешиваются в реальные показатели.

Снимки отправляются каждые 15 секунд и при уходе со страницы; кабинет обновляется каждые 30 секунд и по кнопке «Обновить». Статистика хранится в `.data/statistics.json` и сохраняется после перезапуска сервера. Пока согласий нет, кабинет показывает пустое состояние с нулевыми счётчиками. Никаких демонстрационных пользователей в статистику не добавляется. Хранилище ограничено 10 000 сеансами; при исчерпании лимита новые сеансы не записываются.

Папка `.data` исключена из Git и недоступна через HTTP. Для переноса существующей статистики сохраните её локальную копию вместе с конфигурацией администратора.

## Действия на сайте

- Шесть быстрых услуг заполняют форму обращения: освещение, дороги, транспорт, уборка, озеленение и другая проблема.
- Создание обращения и очистка формы.
- Поиск по теме, описанию и категории; фильтры «Все», «В работе», «Решённые», «Избранное»; изменение порядка и сброс фильтров.
- Сводные счётчики также работают как фильтры.
- В каждой карточке: подробности, избранное, изменение статуса, повтор обращения и удаление.
- Создание и удаление можно отменить в течение 20 секунд. Отмена доступна для последнего такого действия.
- Новости открываются в окне; кнопку подписки можно включить и выключить. Это отметка только в текущей вкладке, без внешних уведомлений.
- Справка объясняет работу сайта.

Это учебные действия: обращения не отправляются в городские службы, изменение статуса не меняет внешние заявки. Обращения, избранное, подписка и настройки существуют в памяти вкладки до перезагрузки.

## Автоматическое предложение адаптации

Ручного запуска наблюдения, кнопок паузы/завершения и расписания на сайте больше нет. Через две минуты активной работы появляется окно «Хотите адаптировать интерфейс?». Считается время взаимодействия с сайтом в активной вкладке и окне. Время простоя более 30 секунд, фоновой вкладки и потери фокуса не учитывается. Пока открыто другое окно сайта, предложение ждёт его закрытия.

Пользователь выбирает вариант и явно подтверждает изменение. Отказ или Escape ничего не меняют. Автоматическое предложение показывается один раз до перезагрузки; настройки можно открыть вручную в любой момент, в том числе администратору. Кнопка возврата восстанавливает стандартный вид. Автоматическое предложение администратору не показывается.

| Вариант | Изменения |
| --- | --- |
| Немного крупнее | Элементы от 44 px, текст формы 14 px, увеличенные интервалы |
| Крупные элементы | Элементы от 52 px, текст 16 px, услуги и варианты в одну колонку |
| Максимально крупные | Элементы от 60 px, текст 18 px, одна колонка, отключение анимаций внутри сайта |

Адаптация охватывает форму, услуги, фильтры и действия с обращениями. Предложение через две минуты позволяет самостоятельно выбрать удобный вид и не является диагностическим выводом.

## Локальный анализ и инструменты администратора

В настройках есть одно добровольное согласие на анализ и сохранение числовых показателей для статистики администратора. После согласия анализ включается автоматически, без отдельной кнопки запуска. Снятие согласия останавливает сбор, очищает местные показатели и удаляет текущий числовой сеанс с сервера. При ошибке удаления появляется кнопка повторной попытки. Настройка внешнего вида доступна и без сбора. После возврата страницы из истории требуется новое согласие. Модель и текст обращений не передаются на сервер; статистика не использует localStorage.

Сбор ограничен рабочей областью сайта. Текст и пароли не сохраняются. В исследовательском задании текст сравнивается с образцом только в памяти; остаются числа. Обрабатываются доверенные события браузера, а программно сгенерированные события не попадают в измерения.

В режиме администратора доступны:

- Текущие показатели и экспорт JSON.
- Четыре синтетических сценария, доступные и во время локального анализа. Кнопка «Текущие показатели» возвращает отображение реальных данных.
- Импорт числовой выборки, размеченного исследования или модели v2; экспорт модели и результатов проверки. Максимальный JSON — 4 МБ. Неудачный импорт сохраняет предыдущую модель.
- Необязательные исследовательские задания ввода текста и выбора объекта.
- Экспорт достаточной реальной сессии с обезличенным кодом участника.
- Очистка числовых показателей и импортированной модели. Очистка аналитики не удаляет обращения.

Требования исследовательской модели сохранены: час активного времени, минимум 200 нажатий, 100 удержаний, 100 интервалов, 30 кликов, 20 маршрутов, три проверки текста и десять попыток выбора цели. При нехватке данных модель воздерживается от вывода. Двухминутное уведомление не сокращает эти требования. Реальной клинически проверенной выборки в проекте нет; синтетические сценарии проверяют программный конвейер и не подтверждают точность оценки моторики людей.

Обучение на размеченном исследовании разделяет участников между обучением и проверкой. Метки 0–3 задаются автором исследования по независимой оценке; программа их не придумывает. Пример содержит 80 синтетических участников по пять сессий. Старые модели с шестью признаками несовместимы с v2.

Применённый интерфейс можно экспортировать в самостоятельный HTML через раздел аналитики. Экспорт очищает пользовательские данные и удаляет интерактивные разделы портала, которым нужны его скрипты; в файле остаются адаптированная форма и работающий локальный список обращений. Исходные файлы не изменяются.

## Проверки и структура

Откройте `http://127.0.0.1:8741/tests/index.html` для обычных браузерных проверок. Полный набор, включая настоящий вход и статистику, запускается в отдельном временном хранилище с тестовым паролем:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tests\Test-Server.ps1 -WithBrowser
```

Без `-WithBrowser` запускаются серверные проверки. Для браузерного запуска используется установленный Chrome. Тесты не меняют настоящие пароль и статистику. Проверки охватывают математику, сбор, модель, кнопки портала, вход/выход, запрет доступа без сессии, сохранение и отзыв статистики, перезапуск сервера, двухминутное предложение и ширины экрана 1440, 768, 390 и 320 px. В тестах время предложения ускорено, ждать две минуты не нужно.

- `server/HandHelperServer.cs` — локальный HTTP-сервер, пароли, сессии, защищённый API и хранилище статистики.
- `js/role.js` — безопасное начальное отображение обычного пользователя.
- `js/admin.js` — вход, восстановление сессии, кабинет статистики и CSV.
- `js/statistics.js` — отправка числовых снимков с согласием и удаление сеанса при отзыве.
- `js/portal.js` — услуги, обращения, поиск, фильтры, новости и справка.
- `js/app.js` — автоматическое предложение, согласие, аналитика, модель и экспорт.
- `js/core.js` — математика, часы активности, кластеризация и проверка достаточности.
- `js/collector.js` — числовые измерения и исследовательские задания.
- `js/adaptation.js` — обратимая адаптация и самостоятельный HTML.
- `js/research.js` — разделение участников и оценка модели.
- `js/runtime.js` — библиотечные функции расписания и сохранения для интеграций; в интерфейсе портала они не используются.
- `tests/` — автоматические браузерные проверки.

Проект не использует сторонние библиотеки. `.qa` и `.test-browser` — служебные артефакты разработки, для запуска не нужны.
